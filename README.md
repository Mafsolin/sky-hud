# Sky HUD

Портативный HUD-тренажёр для **Sky: Children of the Light** на Windows.

Создатель: **@mafsolin**

## Возможности

- три прямоугольные панели по 15 клавиш с текущим и следующими ходами;
- режимы демо, тренировки и ручных шагов;
- карта песни с ручным выбором хода и диапазона для практики;
- единое избранное в каталоге и главной панели;
- импорт собственных `.txt`/`.json` песен в `songs/User Songs/`;
- восстановление последней песни без автоматического запуска;
- настройки и проверка обновлений из GitHub Releases;
- безопасное обновление отдельным updater: конфиг, избранное и пользовательские песни не удаляются.

## Запуск из исходников

```text
python sky_hud.py
python sky_hud.py --check
python -m unittest discover -s tests -v
```

Проект рассчитан на Windows и использует стандартные `tkinter`, `ctypes` и `winsound`.

## Сборка

```text
py -3.12 -m PyInstaller --noconfirm SkyHUD.spec
py -3.12 -m PyInstaller --noconfirm SkyHUD-Updater.spec
```

`SkyHUD.spec` собирает приложение, `SkyHUD-Updater.spec` — sidecar для безопасной замены файлов после выхода приложения.

## Публикация и данные

Репозиторий содержит исходный код, тесты и документацию. Большая коллекция `songs/`, пользовательские песни, локальный конфиг, EXE и архивы не входят в Git; они остаются локальными или публикуются отдельными Release Assets.

Публичный репозиторий: <https://github.com/Mafsolin/sky-hud>
