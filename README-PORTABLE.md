# Sky Notes Portable

Распакуйте архив и запустите `Sky HUD.bat`. Никакой установки Python или других зависимостей не требуется: HUD упакован в `SkyHUD.exe`.

- `Sky HUD.bat` — запуск HUD поверх Sky.
- `SkyHUD.exe` — автономная программа.
- `SkyHUD-Updater.exe` — отдельный процесс безопасного обновления; вручную запускать не нужно.
- `sky-trainer.html` — браузерный тренажёр.
- `songs/` — коллекция нот.
- `songs-manifest.json` — список файлов.

В HUD нажмите `Каталог нот`, найдите песню и дважды кликните по ней.

## Новое управление

- **Загрузить свою песню** в каталоге — выбрать Sky-файл `.txt` или `.json`. Копия сохраняется в `songs/User Songs/`, появляется в поиске и остаётся после перезапуска; исходный файл не меняется. Песня открывается в HUD без автостарта. Разные файлы с одинаковым именем сохраняются отдельно.

- **Открыть карту** — открыть полный список ходов выбранной песни. Клик по ходу показывает его на HUD; кнопки `← Предыдущий` и `Следующий →` листают ходы вручную. Укажите номера начала и конца и нажмите **Ручная практика** — приложение выберет этот отрезок, переключится в пошаговый режим и будет ждать нажатия клавиш; само ничего не проигрывает. **Вся песня** снимает ограничение отрезка.
- **☆ / ★** рядом с названием выбранной песни и в каталоге — это одно общее избранное. Изменение в одном месте сразу отражается в другом и сохраняется между запусками.
- **Скрыть HUD полностью / Показать HUD** — скрывает только три клавиатуры и нижнюю строку; управление остаётся доступным. Играющий ход не сбрасывается.
- **Настройки** — подпись создателя, ссылка на публичный репозиторий и проверка обновлений. При наличии новой версии кнопка **«Обновиться»** скачивает проверенный пакет; конфиг, избранное и `songs/User Songs/` сохраняются.
- Последняя выбранная песня восстанавливается при следующем запуске **без автоматического старта**. **Старт** начинает её с первого хода.
- Левая клавиатура — текущий ход (золотая заливка) и следующий ход (голубой контур); две справа — следующие ходы с голубой заливкой. Если клавиша есть в обоих ходах, на первой карточке видны и заливка, и контур. Текстовые дублирующие подсказки и строка статистики убраны.
- Избранное, последняя песня и состояние видимости хранятся в `sky_hud_config.json` рядом с программой.

Не перемещайте `songs/` отдельно от приложения. Внешний файл песни должен оставаться на прежнем месте; если он недоступен, загрузится пример и появится сообщение.

## Исходники и проверки

`sky_hud.py` — основной исходник. `sky-trainer.html` — отдельная веб-версия, в этой доработке не менялась.

```bash
python sky_hud.py
python sky_hud.py --check
python -m unittest discover -s tests -v
```

GUI-тесты используют временный конфиг и каталог песен, не меняя пользовательские данные.

## Обновления

В **Настройки → Проверить обновления** ничего не скачивается. Кнопка **Обновиться** доступна только для более нового релиза. Нужен доступ к GitHub по HTTPS. Пакет `SkyHUD-Update.zip` обязан иметь SHA-256 в GitHub API; без него установка запрещена. Проверяются размер, хеш, CRC и точный состав файлов. Затем HUD закрывается, отдельный updater ждёт завершения процесса и заменяет только EXE и эту инструкцию.

`sky_hud_config.json`, избранное и все песни остаются нетронутыми. Старые EXE сохраняются рядом в `.sky-hud-backups/`; при ошибке замены выполняется откат. Если автоматический откат заблокирован Windows, резервная копия не удаляется. Подробности ошибки — `sky_hud_update_error.log`. Для ручного восстановления закройте HUD и скопируйте старые EXE из последней резервной папки обратно рядом с песнями.

Сборка (требуется PyInstaller): `py -3.12 -m PyInstaller --noconfirm SkyHUD.spec`; затем `dist/SkyHUD.exe` копируется в корень после закрытия старого HUD.

## История Git

Локальный репозиторий находится в корне проекта, ветка `main`. Метка `baseline-before-hud-update` хранит исходное состояние до доработки. Публичные исходники и релизы: https://github.com/Mafsolin/sky-hud. Личный конфиг и пользовательские песни не публикуются.

Для просмотра: `git log --oneline`, `git diff baseline-before-hud-update -- sky_hud.py`.
Без изменения основной рабочей копии можно получить исходную версию: `git worktree add ../sky-baseline baseline-before-hud-update`.

Исполняемые файлы, ZIP, `build/`, `dist/`, внешняя коллекция `songs/`, снимок `notes/` и локальный конфиг исключены из Git. Они остаются на диске; Git не откатывает эти файлы.

Оформление: прямоугольные панели и клавиши, крупные жирные буквы и контрастная подсветка; без колец, скруглений, градиентов и дублирующих подписей. Цвет используется для смысла: золотой текущий ход и голубые будущие ходы.
